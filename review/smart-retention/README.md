# Smart retention review branch — no deployment
This branch is an integration candidate, not a production release. The deploy branch migration/github-pages is not changed. SQL files in this directory are review-only and must not be applied to a live database. Existing PTG imports retain parsed rows and do not store original workbooks in Supabase Storage; all existing buckets remain excluded. Legacy source chronology must be confirmed by System Admin before dated imports can replace populated legacy values. Source dates are distinct from upload timestamps. This commit contains the Product Master, SRP (manual and workbook), Data Desk, and System Admin UI and server integrations. Registry, cleanup and announcement integration, isolated SQL validation, and other modules still require verification. No automatic cleanup should be activated until the entire candidate passes and release is approved.
